# AllCollegeEvent (ACE) — Complete Feature Discovery & Inventory

## 1. Executive Summary
The AllCollegeEvent (ACE) platform is unified under a single responsive shell with **0 orphaned routes**, **0 dead buttons**, and a global **Explore All Directory (`/explore`)** connecting all 24+ production modules.

---

## 2. Core Feature Matrix by Domain

### A. Opportunity Discovery & Public Hub
- **Events Explorer (`/events`)**: 0-100% AI Match Score, date/city/mode/fee filters, save to watchlist, instant registration.
- **Hackathons Hub (`/hackathons`)**: Cash prize pools, track filters (AI/ML, Web3, Cyber, Cloud), team formation tools.
- **Personalized Stream (`/for-you`)**: 8-dimension match engine with *"Why am I seeing this?"* explainability modals.
- **Smart Search (`/search`)**: Natural language query interpreter extracting intent chips (e.g. Free + Coimbatore + Hackathon).
- **Project Case Study (`/project-showcase`)**: Full presentation suite with keyboard-controlled demo deck (`/project-showcase/demo`).

### B. Coding Hub & Gamified Arcade
- **Interactive Problem Solver (`/coding/practice/two-sum`)**: Multi-language IDE (Python, Java, C++, JS) with live test runners and Socratic AI tutor hints.
- **8 Browser Coding Mini-Games (`/coding/games`)**: Code Builder, Debug The Code, Output Guess, Code Quiz, Algorithm Race, SQL Challenge, Fix The Bug, Memory Match.
- **Learning Academy (`/learn`)**: Structured curriculums for Python Beginner, Full-Stack Web Development, and DSA in C++/Java.

### C. Career & Student Portfolio
- **Student Career Center (`/student/career`)**: Verified internships (ThoughtWorks, Zoho, IITM) and tech jobs.
- **ATS Resume Builder (`/student/resume`)**: 1-Click compiler transforming verified ACE hackathons & coding stats into an ATS-friendly PDF.
- **Application Tracker (`/student/applications`)**: Kanban tracking for applied, shortlisted, and interview statuses.
- **Certificate Wallet (`/certificates`)**: Cryptographic digital certificates with tamper-proof QR verification links.

### D. Multi-Role Workspaces & Governance
- **Student Portal (`/student`)**: Passes, achievements, streaks, and ground AI assistant.
- **Campus Ambassador Command Center (`/ambassador`)**: Student reach, outreach campaigns (`/ambassador/campaigns`), task manager (`/ambassador/tasks`), student directory (`/ambassador/students`), and event reviews.
- **Organizer Workspace (`/organizer`)**: 10-step event creation wizard, AI copywriter studio (`/organizer/ai-tools`), and live QR check-in scanner.
- **Institutional College Workspace (`/college`)**: Department rosters, HOD verifications, and campus symposiums.
- **ACE Admin Risk Center (`/admin/ai-risk`)**: Anomaly radar, duplicate detection, and poster date mismatch verification.
- **Immutable Audit Logs (`/admin/audit-logs`)**: Chronological audit trail of all moderation and administrative decisions.
- **Student Reports Queue (`/admin/reports`)**: Community complaints triage and resolution engine.
- **Support Center (`/support`)**: Help desk ticketing portal.
